# الدورة العملية لهندسة بيانات الذكاء الاصطناعي 🚀

مرحباً بك في **الدورة العملية لهندسة بيانات الذكاء الاصطناعي**! تم تصميم هذا المستودع ليكون دليلاً شاملاً وعملياً لأي شخص يتطلع إلى إتقان هندسة بيانات الذكاء الاصطناعي. سواء كنت مبتدئاً تخطو خطواتك الأولى، أو مهندساً مبتدئاً يتطلع إلى صقل مهاراته، أو محترفاً من المستوى المتوسط/المتقدم يبحث عن مواضيع متقدمة، ستجد هنا موارد قيمة، ومختبرات، ومهام.

🌍 **اللغات:** [English](README.md) | [العربية](README.ar.md) | [Français](README.fr.md)

## 🎯 الهدف
مهمتنا هي مساعدة المجتمع على فهم وإتقان مجال هندسة بيانات الذكاء الاصطناعي من خلال التطبيقات العملية، والاختبارات، والمهام، والموارد عالية الجودة (مقالات، مواقع ويب، كتب، وأوراق بحثية).

## 📚 هيكل الدورة

تنقسم الدورة إلى أربعة فصول رئيسية. يحتوي كل فصل على موارد نظرية، ومختبرات عملية، ومهام، واختبارات للتحقق من معرفتك.

### [1. مقدمة في هندسة البيانات](./01-Introduction-to-Data-Engineering)
- نظرة عامة على هندسة البيانات في سياق الذكاء الاصطناعي.
- مهندس البيانات مقابل عالم البيانات مقابل مهندس تعلم الآلة.
- الأدوات والأنظمة البيئية.

### [2. أنظمة المصدر، واستيعاب البيانات، والمسارات](./02-Source-Systems-Data-Ingestion-and-Pipelines)
- فهم أنظمة المصدر (قواعد البيانات العلائقية، NoSQL، واجهات برمجة التطبيقات).
- تقنيات استيعاب البيانات (دفعات مقابل تدفق).
- بناء مسارات بيانات قوية.

### [3. تخزين البيانات والاستعلامات](./03-Data-Storage-and-Queries)
- بحيرات البيانات، ومستودعات البيانات، وبحيرات مستودعات البيانات.
- تنسيقات التخزين ومحركات الاستعلام.

### [4. نمذجة البيانات، وتحويلها، وتقديمها](./04-Data-Modeling-Transformation-and-Serving)
- النمذجة الأبعاد.
- تحويل البيانات وتقديمها لنماذج الذكاء الاصطناعي ومخازن الميزات (Feature Stores).

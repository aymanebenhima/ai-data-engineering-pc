# AI Data Engineering Practical Course 🚀

Welcome to the **AI Data Engineering Practical Course**! This repository is designed to be a comprehensive, hands-on guide for anyone looking to master AI Data Engineering. Whether you are a beginner taking your first steps, a junior engineer looking to solidify your skills, or a mid-level/senior professional seeking advanced topics, you will find valuable resources, labs, and tasks here.

🌍 **Languages:** [English](README.md) | [العربية](README.ar.md) | [Français](README.fr.md)

## 🎯 Goal
Our mission is to help the community understand and master the field of AI Data Engineering through practical applications, quizzes, tasks, and high-quality resources (articles, websites, books, and research papers).

## 📚 Course Structure

The course is divided into four principal chapters. Each chapter contains theoretical resources, hands-on labs, tasks, and quizzes to validate your knowledge.

### [1. Introduction to Data Engineering](./01-Introduction-to-Data-Engineering)
- Overview of Data Engineering in the context of AI.
- The Data Engineer vs. Data Scientist vs. ML Engineer.
- Tools and Ecosystems (Hadoop, Spark, Cloud platforms).
- Resources, Quizzes, and Intro Tasks.

### [2. Source Systems, Data Ingestion, and Pipelines](./02-Source-Systems-Data-Ingestion-and-Pipelines)
- Understanding Source Systems (Relational, NoSQL, APIs, Streaming).
- Data Ingestion Techniques (Batch vs. Streaming).
- Building robust Data Pipelines (Kafka, Airflow, NiFi).
- Hands-on Labs & Quizzes.

### [3. Data Storage and Queries](./03-Data-Storage-and-Queries)
- Data Lakes, Data Warehouses, and Data Lakehouses.
- Storage Formats (Parquet, Avro, ORC).
- Query Engines and Optimization (Presto, Trino, Snowflake, BigQuery).
- Advanced SQL and Performance Tuning.

### [4. Data Modeling, Transformation, and Serving](./04-Data-Modeling-Transformation-and-Serving)
- Dimensional Modeling (Star Schema, Snowflake).
- Data Transformation (dbt, Spark SQL, Pandas).
- Data Serving (APIs, Feature Stores for AI/ML).
- End-to-End Capstone Project.

## 🛠️ What's Inside Each Chapter?
- `README.md`: Chapter overview and learning objectives.
- `resources.md`: Curated list of books, articles, research papers, and websites.
- `/labs`: Step-by-step practical exercises.
- `/tasks`: Challenges to solve on your own.
- `/quizzes`: Short tests to check your understanding.

## 🌟 Target Audience
- **Beginners:** Start with Chapter 1 and focus on understanding the ecosystem and basic SQL/Python.
- **Juniors:** Deep dive into Pipelines and Transformation using modern tools like Airflow and dbt.
- **Mid-Level/Seniors:** Explore advanced query optimizations, Data Lakehouse architectures, and AI feature serving.

# Laboratoire Section 1 : Console de gestion AWS

## Objectif
Se familiariser avec la console de gestion AWS.

## Étape 1 : Créer un compte AWS
1. Allez sur [aws.amazon.com](https://aws.amazon.com/).
2. Cliquez sur **Créer un compte AWS**.
3. Suivez les instructions pour créer un compte gratuit (Free Tier).

## Étape 2 : Visite de la console
1. **Connexion :** Connectez-vous en tant qu'utilisateur racine.
2. **Barre de recherche :** Cherchez "EC2".
3. **Sélection de la région :** Choisissez l'emplacement de vos serveurs (ex: Paris).
4. **Facturation :** Cherchez "Billing" pour voir vos coûts.

**Félicitations ! Vous avez terminé votre première visite.**

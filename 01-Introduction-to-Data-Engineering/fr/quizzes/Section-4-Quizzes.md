# Quiz Section 4 : Traduire les Exigences

## 🟢 Quiz Facile
**1. Qu'est-ce qu'une "Partie prenante" (Stakeholder) ?**
- [ ] a) Une base de données.
- [ ] b) Une personne qui s'intéresse aux données pour son travail.

## 🟡 Quiz Moyen
**1. Lequel de ces éléments est une "Exigence non fonctionnelle" ?**
- [ ] a) Le pipeline doit calculer l'âge moyen.
- [ ] b) Le pipeline doit se terminer en moins de 5 minutes.

## 🔴 Quiz Difficile
**1. Pourquoi utiliser à la fois Batch et Streaming pour un système de recommandation ?**
- [ ] a) Parce que AWS est moins cher ainsi.
- [ ] b) Le Batch est pour l'historique, et le Streaming pour capturer les clics en temps réel de l'utilisateur.

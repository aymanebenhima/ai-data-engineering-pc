# Quiz Section 3 : Architecture des Données

## 🟢 Quiz Facile
**1. Si vous traitez vos données une fois par jour à minuit, quelle est cette architecture ?**
- [ ] a) Streaming
- [ ] b) Batch

## 🟡 Quiz Moyen
**1. Quel est l'avantage des Microservices ?**
- [ ] a) Toujours moins cher.
- [ ] b) Remplacer ou réparer une petite partie sans casser le reste.

## 🔴 Quiz Difficile
**1. Quel est un exemple de la loi de Conway ?**
- [ ] a) Les données vont plus vite dans le cloud.
- [ ] b) Une entreprise avec trois départements isolés construit trois bases de données isolées.

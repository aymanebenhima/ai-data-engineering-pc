# Mission 1 : Un exemple de cycle de vie de l'ingénierie des données

## Objectif
Appliquer le cycle de vie à un scénario réel.

## Scénario
Vous travaillez pour une application de livraison de repas. À chaque commande, l'application génère un fichier JSON avec le lieu et le prix. Les Data Scientists ont besoin de ces données chaque matin.

## Votre Mission
Expliquez comment construire ce cycle sur AWS :
1. **Génération :** D'où viennent les données ?
2. **Ingestion :** Comment les données entrent-elles dans le système ?
3. **Stockage :** Où stockez-vous les fichiers bruts ?
4. **Transformation :** Comment nettoyez-vous les données ?
5. **Service :** Où mettez-vous les données nettoyées pour les Data Scientists ?

# اختبارات القسم 1: مقدمة في هندسة البيانات والسحابة

## 🟢 اختبار سهل
**1. ما هو الدور الأساسي لمهندس البيانات؟**
- [ ] أ) تصميم الشعارات لواجهة المستخدم.
- [ ] ب) بناء وصيانة مسارات البيانات لنقلها وتنظيفها.
- [ ] ج) إصلاح أجهزة الكمبيوتر المحمولة المكسورة للموظفين.
- [ ] د) كتابة خوارزميات التعلم الآلي النهائية.

**2. أي خدمة من خدمات AWS تُعتبر أساساً "جهاز كمبيوتر افتراضي" في السحابة؟**
- [ ] أ) AWS VPC
- [ ] ب) Amazon EC2
- [ ] ج) AWS S3
- [ ] د) AWS IAM

## 🟡 اختبار متوسط
**1. وفقًا لنموذج المسؤولية المشتركة في AWS، ما هي مسؤولية العميل (أنت)؟**
- [ ] أ) الأمان المادي لمركز بيانات AWS.
- [ ] ب) تحديث البرامج الثابتة على الخوادم المادية.
- [ ] ج) تأمين نظام التشغيل والتطبيقات وبياناتك داخل السحابة.

## 🔴 اختبار صعب
**1. خلال عصر "البيانات الضخمة" (2000s-2010s)، ما هي التقنيات التي استُخدمت بشكل أساسي لحل مشكلة توسيع نطاق الحوسبة؟**
- [ ] أ) قواعد البيانات التقليدية مثل PostgreSQL.
- [ ] ب) وظائف بدون خادم مثل AWS Lambda.
- [ ] ج) تقنيات Hadoop و MapReduce.

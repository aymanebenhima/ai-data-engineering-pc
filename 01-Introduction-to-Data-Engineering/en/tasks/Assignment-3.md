# Assignment 3: Building End-to-End Batch and Streaming Data Pipeline Based on Stakeholder Requirements

## Objective
Translate business stakeholder needs into a concrete Data Engineering architecture.

## Scenario (Requirements Gathering Exercise)
You had a meeting with two stakeholders:
- **Marketing Director (Functional):** "I need a dashboard showing how many total users signed up today. It doesn't need to be live; seeing it tomorrow morning is fine."
- **Data Scientist (Nonfunctional & Functional):** "I need an AI model that recommends products. The model must know what the user just clicked on less than 2 seconds ago."

## Your Task
1. **Extracting Requirements:**
   - Which stakeholder needs a Batch Pipeline? Why?
   - Which stakeholder needs a Streaming Pipeline? Why?
2. **Choosing Tools and Technologies:**
   - List the AWS services you would use for the Batch Pipeline to meet Marketing's needs.
   - List the AWS services you would use for the Streaming Pipeline to meet the Data Scientist's needs.
3. **Reflection:** Draw a simple block diagram (on paper or using Mermaid) showing how the data flows from the Web App to both the Marketing Dashboard and the Data Scientist's Recommender System.

# Section 4 Quizzes: Translating Requirements

## 🟢 Easy Quiz
**1. What is a "Stakeholder"?**
- [ ] a) A type of database.
- [ ] b) A person who cares about the data and relies on it for their job.
- [ ] c) A cloud server.
- [ ] d) A machine learning model.

**2. Which team usually cares the most about making sure the data pipeline doesn't slow down the main website?**
- [ ] a) Marketing
- [ ] b) Sales
- [ ] c) Software Engineers
- [ ] d) Human Resources

## 🟡 Medium Quiz
**1. Which of the following is a "Nonfunctional Requirement"?**
- [ ] a) The pipeline must calculate the average age of users.
- [ ] b) The pipeline must finish running in under 5 minutes.
- [ ] c) The dashboard must show total sales.
- [ ] d) The database must store user email addresses.

**2. If a Data Scientist needs to query massive amounts of user behavior from the past year to retrain a model, which approach is best?**
- [ ] a) A real-time streaming pipeline that updates every second.
- [ ] b) A scheduled Batch Pipeline that runs overnight.
- [ ] c) Printing the data on paper.
- [ ] d) Using an on-premise Excel file.

## 🔴 Hard Quiz
**1. When building a Recommender System, why might you need *both* batch and streaming pipelines?**
- [ ] a) Because AWS charges less money if you use both.
- [ ] b) Batch is needed to train historical data, while streaming is needed to capture the user's real-time clicks on the website right now.
- [ ] c) Streaming is used for data scientists, and batch is used for machine learning engineers.
- [ ] d) You never use both; you must always choose only one.

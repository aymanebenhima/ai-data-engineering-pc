# Section 1 Quizzes: Intro & Cloud

Test your knowledge with these quizzes. They are divided into three difficulty levels: Easy, Medium, and Hard.

## 🟢 Easy Quiz

**1. What is the primary role of a Data Engineer?**

- [ ] b) To build and maintain data pipelines to move and clean data.

**2. Which AWS service is essentially a "virtual computer" in the cloud?**
- [ ] a) AWS VPC
- [ ] b) Amazon EC2

## 🟡 Medium Quiz

**1. According to the AWS Shared Responsibility Model, what is the customer (you) responsible for?**
- [ ] a) The physical security of the AWS data center.
- [ ] b) Updating the firmware on the physical server hard drives.
- [ ] c) Securing the operating system, applications, and your data inside the cloud.
- [ ] d) Making sure the power and cooling in the data center is running.

**2. If a business stakeholder requests a dashboard that updates every 5 seconds, what kind of data pipeline requirement does this translate to?**
- [ ] a) A monthly batch pipeline.
- [ ] b) A real-time streaming pipeline.
- [ ] c) An on-premise Excel export.
- [ ] d) A manual data entry system.

**3. What is a VPC (Virtual Private Cloud)?**
- [ ] a) A public website hosted by AWS.
- [ ] b) A private database that stores only images.
- [ ] c) A logically isolated section of the AWS Cloud where you can launch resources in a virtual network.
- [ ] d) A service that automatically writes SQL queries for you.

## 🔴 Hard Quiz

**1. During the "Big Data" era (2000s-2010s), which technologies were primarily used to solve the problem of scaling compute and storage across distributed clusters before the Cloud became dominant?**
- [ ] a) Traditional RDBMS like PostgreSQL and Oracle.
- [ ] b) Serverless functions like AWS Lambda.
- [ ] c) Hadoop and MapReduce.
- [ ] d) Snowflake and BigQuery.

**2. Which of the following best describes the difference between a Data Engineer and an ML Engineer?**
- [ ] a) A Data Engineer cleans and structures the data, while an ML Engineer focuses on deploying and scaling the predictive models into production.
- [ ] b) A Data Engineer builds predictive models, while an ML Engineer creates the dashboards for stakeholders.
- [ ] c) There is no difference; they are two titles for the exact same job.
- [ ] d) A Data Engineer only works with Cloud technologies, while an ML Engineer only works on-premise.

**3. You are designing an architecture and need to ensure that database servers cannot be accessed directly from the public internet. Which AWS networking concept should you use?**
- [ ] a) Place the EC2 instances in a Public Subnet with an Internet Gateway.
- [ ] b) Use an AWS S3 bucket instead of an EC2 instance.
- [ ] c) Place the database EC2 instances in a Private Subnet within your VPC.
- [ ] d) Give the database an Elastic IP address.
